# Atividade Prática: Seu Filme Favorito

Página web simples dedicada a um filme favorito, construída com a estrutura básica e semântica do HTML5 e estilizada com CSS em arquivo separado.

## O que foi feito

- Estrutura HTML5 válida, com `<!DOCTYPE html>`, `<head>` e `<body>`.
- Título principal (`<h1>`) com o nome do filme, subtítulo (`<h2>`) e parágrafos descritivos (`<p>`).
- Pôster do filme com a tag `<img>` e o atributo `alt` preenchido.
- **HTML semântico:** uso de `<header>`, `<nav>`, `<main>`, `<article>`, `<section>` e `<footer>`.
- **CSS separado:** arquivo `estilo.css` vinculado ao `index.html` pela tag `<link>`.
- **Variáveis CSS:** cores, fonte e espaçamentos definidos em `:root` e aplicados com `var()`.
- **Layout e responsividade:** Flexbox para organizar o pôster ao lado do texto, com `@media` para telas pequenas.
- **Bônus:** conteúdo central envolvido por `<main>` e `<article>`.
